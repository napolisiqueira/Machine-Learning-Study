<h1 align="center">🤖 Machine-Learning-Study - Bootcamp BairesDev - Machine Learning</h1>

<p align="center">
  <b>Este repositório reúne desafios, laboratórios e projetos práticos desenvolvidos durante o <a href="https://www.dio.me/">Bootcamp de Machine Learning da Baires Dev em parceria com a DIO</a>.</b><br>
  Projetado para consolidar fundamentos e aplicações em Python, R e Scilab, focando nas principais técnicas de Machine Learning modernas.
</p>

<hr/>

<h2>📚 Conteúdo do Repositório</h2>
<ul>
  <li><b>Python, R e Scilab Modules:</b> Laboratórios introdutórios e experimentos para aplicações práticas em Machine Learning com Python, R e Scilab.</li>
  <li><b>Binarização:</b> Estudo de pré-processamento e binarização de dados.</li>
  <li><b>SupervisedTraining:</b> Treinamento, validação e teste de modelos supervisionados clássicos.</li>
  <li><b>TransferLearning-Finetunning:</b> Estratégias avançadas de classificação de imagens (CNN do zero vs. Transfer Learning/Fine-tuning com Caltech 101).</li>
</ul>

<h2>🧠 Destaque: TransferLearning-Finetunning</h2>
<ul>
  <li><b>CNN do Zero:</b> Construção e treinamento completo de uma rede convolucional customizada.</li>
  <li><b>Transfer Learning com VGG16:</b> Uso do VGG16 pré-treinado no ImageNet, realizando fine-tuning na última camada para o dataset Caltech 101.</li>
  <li><b>Etapas:</b> Pré-processamento, definição de arquitetura, validação comparativa, exemplos práticos de predição.</li>
  <li><b>Objetivo:</b> Ilustrar os ganhos e a facilidade do reaproveitamento de modelos robustos com Transfer Learning.</li>
</ul>

<hr/>

<h2>🔬 Propósito do Projeto</h2>
<ul>
  <li>Consolidar fundamentos de Machine Learning e ciência de dados em diferentes linguagens.</li>
  <li>Gerar repositório de estudo, consulta e referência para portfólio.</li>
  <li>Permitir fácil adaptação/expansão para novos experimentos e desafios.</li>
</ul>
